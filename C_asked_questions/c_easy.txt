1. Memory layout of C program
	  ┌────────────────────────────────────────┐ High Address - 0xffff ffff
	  │ Environment Variables & Arguments      │ Command Line Arguments(argv, argc, envp)
	  ├────────────────────────────────────────┤
	  │ Stack (Grows Downward ──> )            │ (Local variables, function frames)
	  │      ↓                                 │
	  │      ▲                                 │
	  │ Heap  (Grows Upward <── )              │ (Dynamic memory via malloc/calloc)
	  ├────────────────────────────────────────┤
	  │ Uninitialized Data Segment (BSS)       │ (Global/Static vars initialized to 0)
	  ├────────────────────────────────────────┤
	  │ Initialized Data Segment               │ (Global/Static vars with explicit values)
	  ├────────────────────────────────────────┤
	  │ Text / Code Segment                    │ (Compiled binary instructions)
	  └────────────────────────────────────────┘ Low Address -0x0000 0000
	  
	  Important Distinction: Virtual vs. Physical Memory
	  	When your C program runs, it does not see the physical RAM sticks on your motherboard. 
	  	The operating system hands your program a fake, isolated map called Virtual Memory.
			0x00000000 is the bottom of this fake map.
		  	0xFFFFFFFF (or the 64-bit equivalent) is the top of this fake map.
	  	The OS operates a background translation system to map these virtual addresses to actual, scattered hardware locations in your physical RAM.

3. Header files in c and its usage.
	A header file in C is a file with a .h extension that contains function declarations, macro definitions, data types, and constants.
	The #include preprocessor directive, tells compiler to copy the entire content of that header file directly into your source code before compilation begins.
		Standard Library Headers <>	#include <stdio.h>
		User-Defined Headers ""		#include "my_functions.h"
  3.1. What is the use of Header guard ?
  	A header guard (include guard) is used in C and C++ to prevent a header file from being included more than once during the compilation of a single source file
  	#ifndef GUARD_H    // 1. If GUARD_H is NOT defined...
	#define GUARD_H    // 2. Define GUARD_H immediately.
	// 3. The actual contents of your header file go here
	#endif

  17.3. What is a dangling pointer in C ? Give examples.
  		A dangling pointer in C is a pointer that points to a memory location that has already been deallocated, freed, or gone out of scope.
  		1. Deallocation of Dynamic Memory
  		2. Returning Local Variable Address from a Function
  		3. Variable Going Out of Scope
  		How to Avoid Dangling Pointers
		    • Assign to NULL: Immediately set the pointer to NULL after calling free().
		    • Avoid Local Stack References: Never return the memory address of a non-static local variable from functions.
		    • Use Static Variables: If you absolutely must return a local address, declare the variable as static so its lifetime extends to the end of the program
  17.4. What is wild pointer in C ? Give examples.

20.  Memory allocation/free
	malloc, calloc, realloc and free
	ptr = (typecast*) malloc(byte_size);
	ptr = (typecast*) calloc( num_of_element , Each_element_size);
	free(ptr);
	ptr = realloc(ptr, new_size); //this coding pattern can cause a severe memory leak if the realloc function fails.
		// 1. Allocate to a temporary pointer
		void *temp = realloc(ptr, new_size);

		// 2. Check if the allocation was successful
		if (temp == NULL) {
		    // Handle the error (e.g., log it, free original memory, or exit)
		    // NOTE: 'ptr' is still valid and points to the original memory here!
		    free(ptr); 
		    exit(EXIT_FAILURE);
		}
		// 3. If successful, safely overwrite the original pointer
		ptr = temp;
  20.1. what is the difference between malloc and calloc ? syntax and return type of malloc/calloc
	Feature		malloc (Memory Allocation)				calloc (Contiguous Allocation)
	Initialization	Leaves memory uninitialized (contains garbage data).	Initializes all allocated bits to zero.
	Arguments	Takes 1 argument: total size in bytes.			Takes 2 arguments: number of elements and size of each element.
	Speed		Faster, because it skips the initialization step.	Slightly slower, due to clearing the memory to zero.
	Use Case	General purpose dynamic memory allocation.		Best suited for allocating arrays and structures.
